# Stylish Sign-In Page

A modern, glassmorphism-inspired **Sign-In page** built with **HTML** and **CSS**.  
It features a gradient background, blurred card effect, smooth animations, and responsive design.

## 📂 Project Structure
- `signin.html` → Main Sign-In page structure
- `signin.css` → Styles for layout, colors, and animations

## ✨ Features
- Gradient background with glassmorphism card
- Animated fade-in effect
- Hover scaling on button
- Responsive design for different screen sizes
- Clean placeholders instead of labels
- Link to Sign-Up page

## 🚀 How to Run
1. Clone or download this repository.
2. Open `signin.html` in any web browser.
3. Customize `signin.css` to change colors, fonts, or effects.

## 🔧 Customization
- Change gradient colors in `body` for a new theme.
- Adjust `backdrop-filter` blur for stronger or softer glass effect.
- Add icons inside inputs for a more polished look.
