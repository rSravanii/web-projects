# Project 1: Login Page Project

This project is a simple login page built using **HTML** and **CSS**.

## Files
- `login.html` → The main structure of the login form.
- `login.css` → Styles for the login form and page layout.

## Features
- Username ,Email and password input fields
- Styled login button
- Responsive design basics

## How to Run
1. Download or clone this repository.
2. Open `login.html` in any web browser.
